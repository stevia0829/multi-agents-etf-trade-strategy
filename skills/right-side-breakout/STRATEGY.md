# A股右侧放量突破策略 v2

> 核心修正：**先识别近期局部平台，再判断突破；中长期旧高只作为压力层，不再直接充当短线突破位。**

## 1. 为什么旧逻辑会误判大唐发电

旧版使用：

```text
R20_close = 前20日最高收盘
```

并把它直接当成“当前平台上沿”。

问题是：如果20日窗口前半段存在明显旧高，而最近已经在更低的位置重新横盘，`R20_close` 会把旧套牢区误当成当前平台，从而把“近期横盘后的放量突破”误判成“还没突破”。

大唐发电案例就是如此：近期真正需要交易者观察的是约 5.9~6.0 的短线平台，而不是约 6.9 的旧高。

因此 v2 把价格结构拆成三层：

```text
局部平台突破位 local_breakout
中期压力 mid_pressure
长期压力 long_pressure
```

## 2. 整体流程

```text
股票代码
  ↓
腾讯实时行情 + 120日前复权日K
  ↓
识别完整T0和当前T1
  ↓
7/10/15/20日候选窗口寻找局部平台
  ↓
计算量能 + CLV + MA5/10/20/30
  ↓
判断T0：未启动 / 放量启动 / 局部突破 / 强突破
  ↓
结合T1：承接 / 回踩确认 / 追高 / 二次突破 / 失效
  ↓
输出分层关键价位 + 决策表 + HTML
```

## 3. 局部平台识别

对 T0 之前分别检查 `7 / 10 / 15 / 20` 个交易日。

每个窗口计算：

```text
close_high = max(close)
close_low  = min(close)
median_close = median(close)
range_pct = (close_high - close_low) / median_close
```

平台优先条件：

```text
range_pct <= 8%
```

再计算高点集中度：最近窗口内有多少收盘价落在 `close_high * 0.97` 以上。高点越集中，越说明平台上沿真实存在。

候选平台评分：

```text
score = 高点集中度
        - range_pct惩罚
        - 窗口过长惩罚
```

优先最近、紧凑、上沿多次被测试的平台。

若没有窗口满足8%紧凑度，则退化使用最近10日的局部压力，避免被更早旧高完全干扰。

最终：

```text
local_breakout = 局部平台最高收盘附近
local_high     = 局部窗口最高价
```

## 4. 中长期压力

局部平台用于“是否启动/是否突破”的判断；更远旧高用于“上方空间和二次突破”的判断。

定义：

```text
mid_pressure  = T0前20日最高价/最高收盘区域
long_pressure = T0前60日最高价
```

注意：

```text
price < mid_pressure
```

不代表“短线没有突破”。它只代表：短线突破之后，上方仍有阶段压力。

## 5. T0量价指标

### 5.1 量能

```text
VMA5 = T0前5日平均成交量
volume_ratio = T0.volume / VMA5
```

参考：

- `<1.2`：量能不足
- `1.2~1.5`：温和放量
- `1.5~2.5`：健康放量
- `>2.5`：强放量，需要结合上影和收盘判断分歧

### 5.2 阳线

```text
close > open
```

### 5.3 CLV

```text
CLV = (close-low)/(high-low)
```

```text
CLV >= 0.70
```

表示收盘仍位于全天上方30%区域。

### 5.4 均线

计算：

```text
MA5 / MA10 / MA20 / MA30
```

v2 中 MA20/MA30 **不再是一票否决项**。

例如从低位刚启动时，价格可能先突破短线平台，再于第二天站上MA20/MA30。这种形态应定义为“放量启动”，而不是直接判死刑。

## 6. T0六项评分

六项仍用于解释强弱：

| 条件 | 1分标准 |
|---|---|
| 局部平台突破 | `close >= local_breakout * 1.003` |
| 接近/站上MA20 | `close >= MA20 * 0.995` |
| 接近/站上MA30 | `close >= MA30 * 0.995` |
| 放量 | `volume_ratio >= 1.5` |
| 阳线 | `close > open` |
| 强收盘 | `CLV >= 0.70` |

但最终状态不是机械依赖总分，而是结合“是否接近局部突破位”。

## 7. T0分类

### 未启动

满足以下典型情况：

```text
量能不足
且
距离local_breakout仍较远
```

### 放量启动

适合大唐发电 9月9日这类结构：

```text
volume_ratio >= 1.5
close > open
CLV >= 0.70
close >= local_breakout * 0.97
但尚未有效收盘突破local_breakout
```

含义：资金开始进攻平台，但 T0 尚未完成突破。

### 局部平台突破

```text
close >= local_breakout * 1.003
volume_ratio >= 1.3
close > open
```

若同时 CLV>=0.70，质量更好。

### 强突破

局部突破成立，并额外满足至少一项：

```text
close > MA20 且 close > MA30
或
close > local_high
或
close > mid_pressure
```

## 8. T1确认逻辑

只要 T0 属于：

```text
放量启动
局部平台突破
强突破
```

T1 就进入观察。

### 情况A：优质回踩确认

```text
T1.low 接近 local_breakout ±1%
且
T1.current/close >= local_breakout
```

结论：`优质确认`

### 情况B：一般承接

```text
T1.low >= local_breakout * 0.98
且
T1.current >= local_breakout
```

结论：`T+1承接成立`

### 情况C：追高风险

```text
T1.current / local_breakout - 1 >= 3%
```

结论：`等待回踩，不追高`

### 情况D：二次突破

```text
T1.current > local_high
或
T1.current > mid_pressure
```

结论：`二次突破`

若偏离 local_breakout 已过大，则仍以“不追高”为优先。

### 情况E：回踩过深

```text
T1.low < local_breakout * 0.98
```

结论：`回踩过深，降级观察`

### 情况F：突破失效

若收盘：

```text
T1.close < local_breakout
```

且未快速收回，则本次突破失效。

盘中只能写“盘中跌回/盘中失效风险”。

## 9. 决策表

| T0 | T1表现 | 判断 | 动作 |
|---|---|---|---|
| 未启动 | 任意 | 无右侧结构 | 不参与 |
| 放量启动 | 次日突破local_breakout | 首次右侧确认 | 观察承接，不追瞬间拉升 |
| 局部突破 | 回踩±1%后站回 | 优质确认 | 可考虑分批执行 |
| 局部突破 | 守住-2%且仍站上 | 承接成立 | 进入右侧观察区 |
| 任一启动态 | 偏离突破位≥3% | 追高风险 | 等回踩 |
| 任一启动态 | 突破local_high/mid_pressure | 二次突破 | 观察稳定承接后分批 |
| 任一启动态 | 低点跌破突破位-2% | 回踩过深 | 降级观察 |
| 任一突破态 | 收盘重新跌回平台 | 突破失效 | 放弃本次信号 |

## 10. 大唐发电复盘模板

对于 601991，v2 应按以下思路：

```text
旧高约6.9
    ↓ 只作为长期压力

中期压力约6.1~6.2
    ↓ 作为二次突破参考

近期横盘约5.55~5.95/6.00
    ↓ local platform

9/9 放量阳线 + 强收盘 + 接近平台上沿
    = 放量启动

9/10 盘中突破约5.9~6.0并测试MA20/MA30
    = T1首次右侧确认候选
```

这就是 v2 最重要的变化：

> **“旧高未突破”不再否定“局部平台已经突破”。**
