# Right-side Breakout Skill

## 目标

不要把“20日最高价/最高收盘”机械地当作当前平台上沿。先识别**最近真正形成的局部平台**，再把更远的旧高当作中长期压力。

核心链路：

```text
输入代码
→ 腾讯实时行情 + 120日日K
→ 识别最近完整交易日 T0
→ 识别局部平台（7/10/15/20日候选）
→ 计算量能、CLV、均线、平台突破程度
→ T0分类：未启动 / 放量启动 / 局部突破 / 强突破
→ 当前日 T1：回踩承接 / 追高 / 二次突破 / 失效
→ HTML报告 + 决策表
```

完整规则见 [STRATEGY.md](./STRATEGY.md)。

## 数据处理顺序

1. 腾讯实时接口获取当前价、昨收、开高低、成交量、时间。
2. 腾讯前复权日K获取至少120根日线。
3. 若最后一根K线日期等于实时交易日期，则最后一根视为盘中bar，T0取上一根完整日K。
4. 在 T0 之前分别检查 7、10、15、20 日窗口，寻找最近局部平台。
5. 平台识别优先满足：
   - 收盘价波动区间相对中位价格不超过约 8%；
   - 最近高点集中度较好；
   - 窗口越短、越接近当前，优先级越高；
   - 若没有合格平台，则退化到 10 日局部压力，不再直接使用20日旧高阻断短线判断。
6. 同时保留：
   - `local_breakout`：当前局部平台突破位；
   - `mid_pressure`：20日旧高/阶段压力；
   - `long_pressure`：60日高点/更长期压力。
7. 对 T0 分类，而不是只给 0~6 单一结论。

## T0 分类

- `未启动`：量价和位置均无明显转强。
- `放量启动`：量能、阳线、CLV较好，价格接近局部平台上沿，但尚未有效站上。
- `局部平台突破`：收盘有效站上局部平台上沿，且量价确认。
- `强突破`：局部突破成立，同时站上关键均线或突破更高层压力。

六项评分仍保留，用于解释强弱，但**不再要求所有突破都必须同时站上MA20、MA30**。均线成为质量加分和风险提示，而不是“一票否决”。

## T1 判断

当 T0 为 `放量启动 / 局部平台突破 / 强突破` 时，当前交易日进入右侧确认：

- 回踩局部突破位 ±1% 后重新站回：`优质确认`
- 低点不低于突破位约 -2%，现价仍在突破位之上：`承接成立`
- 高于突破位 ≥3%：`追高风险，等待回踩`
- 突破 `mid_pressure`：`二次突破`
- 跌破突破位约 -2%：`回踩过深`
- 收盘重新跌回局部突破位：`突破失效`

盘中状态只能写“盘中确认/盘中失效”，不能替代收盘结论。

## HTML 必须展示

- 股票名称、代码、腾讯行情时间；
- 当前实时价格和涨跌；
- T0 分类 + 六项评分；
- 局部平台窗口和区间；
- `local_breakout`、`mid_pressure`、`long_pressure`；
- MA5/10/20/30、VMA5、量能倍率、CLV；
- T1 当前状态和偏离突破位百分比；
- 当前最匹配的决策表行；
- 回踩参考区、结构失效位；
- 明确提示“中长期旧高是压力，不等于短线平台突破位”。

## 大唐发电回归案例

`601991` 是本 Skill 的重要回归样例：旧算法曾把约 6.9 的20日旧高当成当前平台上沿，导致把明显的短线右侧启动误判为“未突破”。优化后必须先识别 5.9~6.0 附近的近期局部平台，再把 6.1~6.2 和更高旧高作为后续压力层。

## 结论用语

使用：

- `未启动`
- `放量启动`
- `局部平台突破`
- `强突破`
- `T+1盘中承接成立`
- `优质确认`
- `等待回踩，不追高`
- `二次突破`
- `回踩过深`
- `突破失效`

不要写“必涨”“稳赚”“确定买入”。
