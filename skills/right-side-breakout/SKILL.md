# Right-side Breakout Skill

## 目标

对一个沪深 A 股代码执行确定性的技术规则分析。不要仅凭语言模型主观判断 K 线；优先运行脚本，让脚本获取腾讯财经数据、计算指标和规则状态，再基于计算结果解释。

完整规则见 [STRATEGY.md](./STRATEGY.md)。

## 输入

必须有一个 6 位 A 股代码，例如：

```text
601991
000001
300750
```

也接受：

```text
sh601991
sz000001
```

## 执行

在仓库根目录运行：

```bash
python skills/right-side-breakout/scripts/analyze_stock.py <股票代码>
```

例如：

```bash
python skills/right-side-breakout/scripts/analyze_stock.py 601991
```

默认生成：

```text
reports/<代码>-right-side-breakout.html
```

如果需要结构化数据：

```bash
python skills/right-side-breakout/scripts/analyze_stock.py 601991 --json
```

## 数据和判断顺序

1. 使用腾讯财经实时接口取得当前价、昨收、开高低、成交量等。
2. 使用腾讯财经前复权日 K 取得至少 80 根日线。
3. 识别最后一个完整交易日 T0：
   - 若 K 线最后日期与实时行情交易日期相同且当前仍为盘中，则 T0 使用上一根完整 K 线；
   - 若日 K 尚未包含今日，则最后一根 K 线就是 T0。
4. 对 T0 计算：MA5/10/20/30、前 5 日均量、前 20 日平台最高收盘、前 20 日最高价、CLV。
5. 根据 STRATEGY.md 的六项条件计算 0~6 分。
6. 如果 T0 得分 >= 5，使用当前实时行情判断 T+1 是否守住突破位。
7. 生成 HTML 报告。

## 输出要求

最终 HTML 必须至少包含：

- 股票代码、股票名称、行情时间；
- 实时价格及涨跌；
- T0 六项突破评分；
- “前一日是否放量突破”的明确结论；
- R20_close、R20_high、MA20、MA30、T0 low 等关键价位；
- 当前 T+1 承接状态；
- 右侧交易执行建议；
- 完整决策表，并高亮当前最匹配的一行；
- 指标明细和风险提示；
- 数据源/数据时间，明确区分盘中状态和收盘确认。

## 结论用语

优先使用规则状态，而不是确定性投资指令：

- `未形成突破`
- `观察`
- `突破候选`
- `高质量突破候选`
- `T+1盘中承接成立`
- `等待回踩，不追高`
- `回踩过深，降级观察`
- `突破失效`

不要写“必涨”“稳赚”“确定买入”。

## 数据异常

腾讯接口失败、字段不足或交易日无法识别时：

1. 不猜测数据；
2. HTML 明确显示数据获取失败；
3. 命令返回非 0 状态；
4. 提示稍后重试。
