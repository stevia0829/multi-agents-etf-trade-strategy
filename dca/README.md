# 4%定投（雷牛牛方法）

## 这是什么

一个**只用规则、不用判断**的定投框架，来源是公众号「研究员雷牛牛」的 4% 定投法。

核心三条：

1. **只在低估时启动**（指数估值分位 ≤ 20%）
2. **资金分 10 份**，首笔买 1 份建底仓
3. **以上一笔买入价为基准，每跌 4% 加 1 份**（链式触发，不是以首笔为基准）

卖出：估值进入高估（≥ 80% 分位）**且** 盈利 ≥ 15% → 先卖一半，从最高点回落 4% 再卖剩余。

```

```

## plan.json 字段

| 字段 | 含义 |
|---|---|
| `code` | ETF 代码 |
| `name` | 名称（推送里必须带名称，这是硬规则） |
| `index_code` | 蛋卷估值接口的指数代码，如 `SZ399006` / `SZ399989` / `HKHSTECH` |
| `metric` | 主观察指标，`PE` 或 `PB`（决定用哪个分位判四档） |
| `base` | 首笔底仓价（第 1 档触发价） |
| `total` | 该标的总投入金额（元） |
| `parts` | 分几份，默认 10 |
| `step` | 触发步长，默认 0.04（4%） |
| `bought_parts` | **已买入的档数**，买完必须手动 +1，否则日报会重复提醒 |
| `note` | 备注 |

第 i 档触发价 = `base × (1 - step)^(i-1)`，收盘价 ≤ 该价即视为触发。

## 数学特性

- 10 份全部打完需要累计下跌 **30.8%**（`1 - 0.96^9`）
- 全部打完时持仓均价约在首笔价下方 **17.3%**
- 反弹回首笔价时浮盈约 **+21%**
- 代价：要预留足额资金，并承受打进 10 档时的账面浮亏（约 -13%）

## 执行纪律

- 触发判定用**收盘价**，不看盘中（避免插针假信号）
- **跳空跌破两档也只补一档**，不要一次打两份
- 单标的上限：总资产的 15%
- 每档买完更新 `bought_parts`
- 止盈用双条件：估值 ≥ 80% 分位 且 盈利 ≥ 15%

## 自动更新

服务端每日 15:20（交易日）自动生成报告并推送到本目录。
改 `plan.json` 提交后，下一次运行自动生效（运行前会先 `git pull`）。
