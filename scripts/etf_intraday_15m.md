# ETF Strategy：15 分钟盘中复核

在日线 advice 外单独运行。读取当日早报 JSON 的主推和精选，和最新持仓取并集去重。缺早报时仍能盯持仓；缺持仓时显示未知，不冒充空仓。它不改早报、原有持仓成本、止盈止损或交易记录。

## 运行

需要 Python 3.9+，无额外依赖。按实际部署目录填写路径：

```sh
python3 scripts/etf_intraday_15m.py \
  --report-dir report --hold-file current_holds.json \
  --state report/intraday/15m-overlay-state.json
```

持仓文件兼容 `{"holds":[{"code":"159687","qty":100}]}`、`{"codes":["159687"]}`、裸数组字符串或对象。如果现有桥维护的是 `holding.json`，用实际路径。空数组表示明确空仓；文件缺失或损坏表示未知。早报采用 `etf-report-YYYYMMDD-HHMMSS.json`，时间以北京时间解释，只接受当天生成、非尾盘预览的报告。主推和精选仅供盘中复核，不在盘中重选或重跑 LLM。

计划在上海时间 09:46、10:01、10:16、10:31、10:46、11:01、11:16、11:31、13:16、13:31、13:46、14:01、14:16、14:31、14:46、15:01 执行。等收完一根 K 线再留一分钟给数据到达。周末和非窗口跳过。运行环境应使用现有的交易日判断；程序未内置节假日表，没有本时点有效 K 线时只返回数据不可用，不发交易信号。若调度器只支持整日每 15 分钟，可改用以上分钟偏移并让程序检查窗口。

- 行情沿用项目腾讯数据源，使用腾讯财经代理的日线及 15 分钟接口。日线优先取前复权，无前复权字段时读原始日线，指标各自在其周期内比较。上线时确认运行环境可访问该接口且可稳定取得已结束 K 线。
- 昨日收盘在日线 MA20 上方、MA20 高于五日前，才有多头环境。前一根 15 分钟 K 线触及 EMA20 后收回，下一根收盘突破其最高价并站上 EMA20，记为技术确认。早报主建议或个股建议不是 buy 时，不产生新的入场观察提醒。
- 对持仓，只提醒收盘从 EMA20 上方跌到下方；不把它作为自动止损。T+1 标的能否卖出以实际可卖仓位为准。
- 不读取或推断 IOPV，也不验证成交成本。跨境 ETF 的技术信号不能当作折溢价已核验的买点。盘口风控继续由人工确认。未移植沪金 ATR 参数。
- 调度通知只报告 `alerts`（新增技术确认或持仓跌破）、`new_problem`、`recovered`；平时静默。不把逐次结果发到微信，不下单。状态文件用于对同一收盘时点、同一代码去重，调度应串行运行。

本地验证：同目录执行 `python3 -B -m unittest discover -s . -p 'test_etf_intraday_15m.py'`。可用 `--fixture /path/to/quotes.json --as-of 2026-11-16T10:01:00+08:00` 做离线重播，行情 JSON 格式为 `{代码: {"15": [标准化的时间,开,收,高,低,量字符串], "101": [...]}}`。离线结果仅验证行为，不是实盘收益或回测。
